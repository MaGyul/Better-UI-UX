# 인게임 에디터

UI 화면을 연 채로 **F8** 을 누르면 에디터가 켜집니다. 편집 결과는 원본 XML 텍스트에 반영되므로
**주석, 들여쓰기, 속성 순서가 그대로 보존**됩니다.

## 켜기

기본값은 꺼짐입니다(모드팩 배포용). 개발할 때만 켜세요.

| 방법 | 설명 |
|---|---|
| `config/better-uiux/config.toml` 의 `[editor] enabled = true` | 영구 설정 |
| JVM 인자 `-Dbetteruiux.editor.enabled=true` | 설정 파일보다 우선(모드팩 제작자가 고정할 때도 이 방식) |
| `/uiux edit <id>` | 화면을 열면서 에디터까지 켠다 |
| `/uiux editor` | 열린 화면 없는 **빈 에디터**를 연다. 가운데 목록(또는 `File` 메뉴)에서 편집할 화면을 고르거나 새 화면을 만든다 |

꺼져 있으면 F8 을 눌러도 안내만 나오고, 에디터 코드는 메모리에 올라오지 않습니다.

## 화면 구성

```
┌──────────────────────────────────────────────────────────┐
│ Save Undo Redo  Dup Del Grid                    demo.xml │ ← 도구 모음
├───────────────┬──────────────────────────┬───────────────┤
│ 블록(끌어다놓기)│                          │ 속성          │
│ [라벨][버튼][패널]│        (편집 중인 화면)    │ tag  panel #1 │
│ [세로][가로][이미지]│                         │ id    a       │
│ [여백]         │                          │ width 50      │
├───────────────┤                          │ ...           │
│ 구조       - + │                          │               │
│ ▣ screen       │                          │               │
│  -▣ panel#a    │                          │               │
│  -▣ column#col │                          │               │
└───────────────┴──────────────────────────┴───────────────┘
```

## 스크래치처럼 다루기

| 하고 싶은 일 | 방법 |
|---|---|
| **요소 추가** | 왼쪽 **블록**을 화면이나 구조 트리로 **끌어다 놓기**. 놓을 컨테이너는 초록 윤곽선으로 표시된다 |
| 정확한 위치에 놓기 | 패널처럼 자유 배치 컨테이너 위에 놓으면 요소의 가운데가 놓은 지점에 온다(`x`/`y` 로 기록) |
| 줄 사이에 끼워 넣기 | 세로/가로 묶음 위에 놓으면 초록 선이 들어갈 자리를 보여준다 |
| 간단히 추가 | 블록을 끌지 않고 **클릭**하면 선택한 컨테이너 맨 뒤에 추가 |
| **구조 바꾸기** | 구조 트리의 행을 끌어 다른 행의 **위쪽 가장자리(앞)** / **가운데(안)** / **아래쪽 가장자리(뒤)** 에 놓기 |
| **삭제** | 요소(화면 또는 트리 행)를 **왼쪽 블록 칸으로 끌어다 놓기** — 칸이 빨갛게 변한다. `Delete` 키도 된다. `Ctrl+Z` 로 되돌릴 수 있다 |
| 자기 안으로 넣기 | 자기 자신의 하위로는 놓을 수 없다(빨간 윤곽선) |
| 놓기 취소 | 끄는 동안 `Esc` |

### 구조 트리 접고 펼치기

- 자식이 있는 행 앞의 **`-` / `+`** 를 눌러 접고 펼칩니다.
- 머리말의 **`-`** 는 모두 접기, **`+`** 는 모두 펼치기.
- 화면에서 요소를 클릭하면 그 요소가 보이도록 조상 행이 자동으로 펼쳐집니다.
- 접힘 상태는 편집을 해도 유지됩니다(id 가 있으면 id 로 기억).

## 화면 밖으로 못 나가고, 가장자리에 붙이면 따라다닌다

- **범위 제한**: 끌어서 이동, 크기 조절, 방향키, 블록 놓기 모두 **부모 안으로만** 가능합니다(루트의 자식이면 게임 화면 안). 화면 밖으로 나가지 못합니다.
  (속성 칸에 숫자를 직접 입력하는 것은 제한하지 않습니다.)
- **기준점 자동 지정**: 요소를 부모의 **오른쪽/아래쪽 끝** 가까이(8px 이내)에 놓으면 그 끝을 기준점(`anchor`)으로 삼아
  `anchor="top-right"` 처럼 기록합니다. 이후 창 크기가 바뀌어도 요소가 그 끝에 붙어 있습니다. **가운데 선**에 맞추면(분홍색 정렬선) 가운데 기준이 됩니다.
  왼쪽 가장자리로 가져가면 다시 left/top 기준으로 돌아옵니다.
  - 이미 정해 둔 기준점은 **끈적합니다**: 그 기준선에서 12px 이내로만 움직이면 바뀌지 않습니다(예: 가운데 정렬된 창을 살짝 옮겨도 가운데 기준 유지).
  - 팔레트에서 놓을 때는 오른쪽/아래쪽 끝(6px 이내)만 추론합니다.
  - 툴바 **`Anchor:auto` / `Anchor:keep`** 으로 자동 지정을 끌 수 있습니다.
- **기준점을 직접 바꿔도 제자리**: 속성 패널에서 `기준점`을 `top-right` 등으로 바꾸면 요소는 지금 자리에 그대로 있고, `x`/`y` 가 새 기준점에 맞게 다시 계산됩니다.

## 화면 이동과 패널 접기

- **자동 이동**: **구조 트리에서 고른** 요소가 양옆 패널에 가려지거나 화면 밖이면, 보이게 되는 데 **필요한 만큼만** 화면이 부드럽게 옮겨집니다
  (가운데로 끌어오지 않습니다 — 화면 구석의 요소를 가운데로 데려오면 게임 화면 전체가 크게 밀려 보이기 때문). 이미 보이는 축은 건드리지 않습니다.
  화면에서 직접 누른 요소는 이미 눈앞에 있으므로 화면을 움직이지 않습니다. 배경 패널처럼 작업 영역보다 큰 요소도 옮기지 않습니다.
- **새 요소 위치**: 블록 클릭이나 구조 트리에 놓아서 추가한 요소는 지금 보고 있는 화면 한가운데에 놓입니다(패널에 가려진 구석이 아니라).
  화면 위에 직접 놓으면 놓은 지점에 놓입니다.
- **직접 이동**: 마우스 **휠**(캔버스 위) 또는 **가운데 버튼 드래그**. 툴바 `Fit!`(옮겨 둔 상태에서만 노랗게 표시) 또는 `Home` 키로 처음 위치로 돌아옵니다.
- **화면 경계 표시**: 화면을 옮겨 두면 실제 게임 화면의 경계를 파란 테두리로 그리고 바깥을 어둡게 해서 "screen 이 어디인지" 알 수 있습니다.
- **드래그 중 자동 숨김**: 화면에서 요소를 끌어 옮기는 동안에는 양옆 패널이 숨겨져 화면 전체가 보이고, 왼쪽 아래에 **삭제 칸**이 나타납니다.
  거기에 놓으면 삭제됩니다. 블록/트리 행을 끄는 동안에는 오른쪽 속성 패널만 숨겨집니다.
- **직접 접기**: 패널 가장자리의 작은 탭(`<` / `>`)을 누르면 그 패널이 접히고, 접힌 자리의 탭으로 다시 펼칩니다. 접으면 작업 영역이 그만큼 넓어집니다.
- `Tab` 키는 도구 모음까지 모두 숨기거나 보입니다.

## 속성 칸 편집 (채팅창과 같은 조작)

속성 값을 클릭하면 **전체가 선택**되어 바로 입력하면 값이 바뀝니다. Enter 로 확정, Esc 로 취소, 칸 밖을 누르면 확정됩니다.

| 조작 | 동작 |
|---|---|
| 클릭 | 그 자리에 커서 |
| 클릭하고 끌기 | 글자 범위 선택 |
| 더블클릭 | 그 단어 선택 |
| `Shift`+`←` `→` `Home` `End` | 선택 확장 |
| `Ctrl`+`←` `→` | 단어 단위 이동 (`Ctrl`+`Shift` 는 단어 단위 선택) |
| `Ctrl`+`Backspace` / `Ctrl`+`Delete` | 앞 / 뒤 단어 삭제 |
| `Ctrl`+`A` | 전체 선택 |
| `Ctrl`+`C` / `Ctrl`+`X` / `Ctrl`+`V` | 복사 / 잘라내기 / 붙여넣기 (채팅창과 같은 클립보드, 줄바꿈은 공백으로) |
| `←` `→` | 선택이 있으면 선택을 접고 시작/끝으로 |

## 그 밖의 조작

| 동작 | 방법 |
|---|---|
| 선택 | 화면의 요소 클릭, 또는 구조 트리 행 클릭 |
| 이동 | 선택한 요소를 드래그. 자유 배치 부모에서는 `x`/`y` 오프셋, 세로/가로 묶음에서는 순서가 바뀐다 |
| 크기 조절 | 선택한 요소의 8방향 손잡이를 드래그 → `width`/`height` |
| 정렬 보조 | 다른 요소의 가장자리/중심, 부모의 가장자리/중심에 자동으로 달라붙고 분홍색 선이 보인다. `Grid` 로 8px 격자 스냅 |
| 속성 수정 | 오른쪽 패널의 값을 클릭 → 입력 → Enter(확정) / Esc(취소). 비우면 속성이 제거된다 |
| 복제 | `Ctrl+D` 또는 `Dup` (복제본의 `id` 는 `_copy` 가 붙어 겹치지 않는다) |
| 미세 이동 | 방향키(1px), `Shift`+방향키(8px). 세로/가로 묶음 안에서는 순서를 한 칸 이동 |
| 실행 취소 / 다시 | `Ctrl+Z` / `Ctrl+Y` (또는 `Ctrl+Shift+Z`). 드래그 한 번(끌어 놓기 포함)은 한 단계 |
| 저장 | `Ctrl+S` 또는 `Save`. `config/better-uiux/ui/<id>.xml` 에 원자적으로 쓴다 |
| 패널 숨기기 | `Tab` |
| 드래그 취소 | 끄는 동안 `Esc` |
| 에디터 끄기 | `F8` |

## 색, 이벤트 자동 완성, 최소 크기, 피드백

- **컬러피커**: `배경` / `글자색` / `테두리색` 칸을 누르면 아래에 컬러피커가 열린다(채도·명도 사각형, 색조 막대, 투명도 막대, 마인크래프트 기본 16색/투명).
  피커를 만지면 칸의 글자(`#RRGGBB` 또는 `#AARRGGBB`)가 바뀌고 화면에 바로 미리 보이며, 글자를 직접 입력해도 피커가 따라온다. Enter 로 확정(실행 취소 한 번), Esc 로 원래 색으로 되돌린다.
  색 칸 오른쪽에는 현재 색 견본이 보인다.
- **클릭 이벤트**(`onClick`) 칸은 입력하는 동안 등록된 이벤트(액션) id 를 채팅처럼 자동 완성한다.
  `↑`/`↓` 로 후보 고르기, `Tab` 또는 후보 클릭으로 채우기, Enter 로 확정.
- **row/column 최소 크기**: 안에 요소가 있는 row/column 은 내용보다 작게 줄일 수 없다(손잡이 드래그, 직접 입력 모두).
  요소를 넣었을 때 고정 크기 컨테이너가 모자라면 내용에 맞게 자동으로 커진다.
- **상단 바 아래 요소**: 도구 모음의 버튼이 아닌 빈 곳은 아래 캔버스로 통과하므로, 바 밑으로 들어간 요소도 눌러서 끌어낼 수 있다.
  접기 탭은 세로 가운데로 옮겨 모서리 요소를 가리지 않는다.
- **호버/눌림/포인터**: 버튼, 탭, 속성 칸은 마우스를 올리면 밝아지고 누르는 동안 어두워진다. 포인터는 버튼 위 손가락, 글자 칸 위 I빔,
  선택한 요소 위 이동, 좌우/상하 손잡이 위 크기 조절, 컬러피커 위 십자로 바뀐다. UI 문서에서는 CSS `cursor` 속성으로 요소별 포인터를 지정할 수 있다.

- **에디터 닫기**: 툴바 오른쪽의 **`Exit`** 버튼, `F8`, 또는 **아무것도 선택하지 않은 상태에서 `Esc`**.
- **접어 둔 속성 패널**: 요소를 선택하고 있는 동안은 잠깐 펼쳐 보이고, 선택이 풀리면 다시 접힌다(요소를 끄는 동안 숨는 것은 그대로).
- **템플릿(`<use>`)**: 템플릿으로 만들어진 요소는 구조 트리에 `use` 로 나타나고, 속성 패널에서 `<use>` 의 매개변수(text, action …)를 고칠 수 있다.
- **IME**: 한글 등 조합 중인 글자는 칸 위에 조합창으로 표시된다(마인크래프트 기본 입력칸과 같은 창).

- **저장 확인**: 저장하지 않은 변경이 있을 때 `Exit` / `Esc` / `F8` 로 닫으면 "저장 후 닫기 / 저장 안 함 / 취소" 창이 뜬다(Enter = 저장 후 닫기, Esc = 취소).
- **툴바 숨기기**: 툴바의 `Hide` 로 숨기면 화면 맨 위 가장자리에 마우스를 1~2초 올려 둘 때만 나타나고, 벗어나면 다시 숨는다(`Pin` 으로 고정 표시로 복귀). 요소를 끄는 동안에도 툴바는 숨는다.
- **임시로 펼쳐진 속성 패널**: 접어 둔 패널이 요소를 선택해서 잠깐 펼쳐졌을 때도 접기 탭이 남아 있어 그 선택 동안 다시 닫을 수 있다.
- 아래쪽 안내 문구는 작업 영역 가운데에 어두운 바탕 위로 표시된다.

- **툴바 호출**: 숨긴 툴바는 맨 위 가장자리에 마우스를 올리면 가로로 긴 얇은 막대가 툭 튀어나오고, 1~2초 뒤 전체가 나타난다.
- **안내/알림**: 아래 안내 문구는 늘 가운데 맨 위에 떠 있고, 길면 좌우로 스크롤된다. "저장됨" 같은 알림은 오른쪽 아래에 서서히 나타났다가 몇 초 뒤 서서히 사라진다. 저장 확인 창이 떠 있는 동안 뒤의 요소에는 호버 효과가 전해지지 않는다.
- 에디터를 닫으면(Exit/Esc/F8) 열려 있던 화면까지 그대로 닫히고 채팅 안내도 띄우지 않는다.

- **접어 둔 양옆 패널**도 툴바처럼, 화면 왼쪽/오른쪽 가장자리에 마우스를 올려 두면 얇은 막대가 튀어나오고 1~2초 뒤 패널이 나타난다(벗어나면 다시 접힘). 이때 나타난 패널은 작업 영역을 밀지 않고 위에 겹쳐 보인다.

- **접힘 상태 저장**: 왼쪽/오른쪽 패널과 툴바의 접힘 상태는 `config/better-uiux/config.toml` 의 `[editor]` (`leftCollapsed`, `rightCollapsed`, `toolbarHidden`)에 저장되어 다음 실행에도 유지된다.
- 개선 제안과 우선순위는 [editor-roadmap.md](editor-roadmap.md) 참고.

## 속성 편집기 / 새 기능

- **종류별 편집기**: `기준점` `정렬` 같은 값은 목록 메뉴, `보임` `사용` `체크됨` 은 클릭으로 켜고 끔, 숫자(너비·높이·간격…)는 `-`/`+` 버튼 또는 편집 중 ↑/↓(Shift 면 8).
- **속성 패널**: 행이 많으면 휠로 스크롤, `레이아웃` / `모양` 머리줄을 눌러 접고 펼친다.
- **도움말**: `F1` 또는 `?` (툴바 `?` / `View ▸ 도움말`).
- **복사/붙여넣기**: `Ctrl+C` `Ctrl+X` `Ctrl+V` 는 요소 단위(시스템 클립보드에 XML 로 들어가므로 다른 화면 파일로도 붙여넣을 수 있다). id 가 겹치면 `_copy` 가 붙는다.
- **감싸기/풀기**: `Wrap ▸ row/column/panel/stack` 또는 `Ctrl+G`(column), 풀기는 `Wrap ▸ 풀기` 또는 `Ctrl+Shift+G`. 자유 배치 요소를 감싸면 `x` `y` `anchor` 는 감싼 컨테이너로 옮겨 자리가 유지된다.
- **정렬**: `Align` 메뉴(9방향). 자유 배치 부모에서는 기준점을 지정하고 오프셋을 지우며, row/column 안에서는 교차축 정렬(`align-self`)을 쓴다.
- **순서 이동**: `[` 뒤로 / `]` 앞으로(같은 부모 안, 그리는 순서).
- **View 메뉴**: `XML 보기`(읽기 전용, 선택한 요소 줄 강조), `상태 미리보기`(선택한 요소의 `:hover` / `:active` 스타일 강제 표시).
- **저장 충돌**: 에디터 밖에서 파일이 바뀐 뒤 저장하면 경고만 하고, 한 번 더 저장해야 덮어쓴다.
- **툴바 툴팁**: 버튼에 마우스를 잠시 올리면 설명이 뜬다.
- **블록 팔레트 탭**: `기본 / 입력 / 구조`. 입력 위젯과 격자·스크롤·탭·대화상자는 [widgets.md](widgets.md) 참고. `item`(아이템 id)과 `onChange` 칸은 자동 완성된다.

- **아이템 선택 상자**: `아이템 id` 칸(▦)을 누르면 아이콘 격자(8열)가 뜬다. 휠로 스크롤, 글자를 치면 id 로 검색, 아이콘을 누르면 적용(Esc/바깥 클릭으로 닫기).
- **채움색**: `progress`(`bar-color`), `slider`(`fill-color`), `checkbox/radio`(`check-color`)의 색도 속성 패널에서 컬러피커로 바꾼다.
- **좁은 창**: 툴바 버튼이 다 안 들어가면 넘치는 버튼이 `...` 메뉴로 들어간다.

- **scroll / tabs 편집**: `scroll` 위에서 휠을 돌리면 그 안의 내용이 스크롤되어 가려진 요소도 고를 수 있다(캔버스 이동은 scroll 밖에서). 구조 트리에서 가려진 요소를 고르면 보이는 위치까지 자동으로 스크롤된다. 탭 머리글을 누르면 탭이 전환된다.

- **여러 개 선택**: `Ctrl`/`Shift`+클릭(캔버스·구조 트리)으로 선택에 넣고 빼며, 빈 곳을 끌면 사각형 안에 완전히 들어온 요소가 모두 선택된다. 끌기·방향키는 모두 함께 움직이고, `Delete`/`Ctrl+D`/`Align` 도 선택 전체에 적용된다(실행 취소는 한 번에). `Esc` 로 대표만 남기고, 그냥 클릭하면 하나만 남는다. 속성 패널은 대표 요소만 보여 준다.
- **구조 트리 검색**: 트리 머리말의 `검색` 칸을 누르고 입력하면 태그·id·글자로 바로 걸러진다(일치하는 요소의 부모도 함께 보임). 비우고 Enter 로 해제.

## 알아둘 것

- 기본 제공 화면(`demo` 등)을 처음 저장하면 사용자 폴더에 복사본이 생기고, 이후로는 그 파일이 우선합니다. 원본은 건드리지 않습니다.
- 값이 **스타일시트로 정해진** 속성을 고치면 인라인 `style` 에 기록합니다(XML 속성은 스타일시트에 지므로).
  이미 XML 속성이나 인라인 style 에 있던 값은 그 자리에서 고칩니다.
- `<include>` / `<use>` 로 확장되어 생긴 요소는 원본 파일에 없으므로 선택되지 않고, 대신 원본에 있는 가장 가까운 조상이 선택됩니다.
- 편집 중에는 애니메이션과 호버 효과가 꺼지고, 파일 변경 감시(핫리로드)는 무시됩니다.
- 속성 패널의 이름은 한글로 보입니다(너비=width, 높이=height, 바깥여백=margin, 안쪽여백=padding, 기준점=anchor, 글자색=color …). 파일에는 원래 이름으로 기록됩니다.
- 글자 입력은 속성 칸을 편집하는 동안에만 켜집니다(마인크래프트 26.x 는 SDL 로 입력을 받아 "텍스트 입력 시작"을 따로 켜야 합니다).
- 입력이 이상할 때는 `-Dbetteruiux.debug=true` 로 실행하면 에디터가 받은 마우스/키/글자 이벤트가 로그에 남습니다.
- 아직 없는 것: 스타일시트 규칙 직접 편집, 해상도/GUI scale 미리보기, 서버 정책으로 에디터 차단, raw XML 보기.

## 새 화면과 저장

- `File` → `새 화면: 빈 화면/대화상자` 는 **파일을 바로 만들지 않는다.** 제목에 `(새 파일 - 저장 전)` 이 붙은 채로 열리고, 처음 저장(Ctrl+S 또는 `Save`)할 때 `new_N.xml` 이 생긴다.
  고치지 않고 닫거나 다른 화면으로 가면 아무 파일도 남지 않는다. 고친 뒤 닫으려 하면 평소처럼 저장 여부를 묻는다.
- 빈 에디터에는 `Save`/패널이 없고 `File`(과 `Exit`)만 있다. 에디터가 꺼져 있으면(`config.toml` 의 `[editor] enabled`) 안내만 나온다.

## 고급 CSS 속성 (속성 패널의 접힌 섹션)

선택한 요소의 속성 패널 맨 아래에 접힌 섹션 세 개가 있다. 헤더를 눌러 펼친다. 값은 일반 속성과 같은 규칙으로 저장된다
(이미 `style=""` 에 있으면 거기를, 시트가 정한 값이면 inline 으로 덮어쓰기, XML 속성이면 속성을).

- **크기·배치**: `min/max-width/height`, `box-sizing`, `position`, `z-index`, (flex 안에서) `grow`·`flex-shrink`·`align-self`·`order`,
  `flex-wrap`, (grid) `grid-template-columns/rows`·`grid-column`·`grid-row`
- **글자**(label/button): `font-size`, `font-weight`, `line-height`, `letter-spacing`, `text-align`, `vertical-align`, `white-space`, `text-transform`, `text-overflow`, `text-decoration`
- **효과**: `border-style`, `border-radius`, `box-shadow`, `outline-width/color/offset`

숫자 칸은 `-`/`+` 와 ↑/↓(Shift = 8)로 조절한다. 지원 범위와 문법은 [uicss-reference.md](uicss-reference.md).
